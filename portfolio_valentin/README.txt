PORTFOLIO PERSONAL - VALENTÍN DEL TORO IZQUIERDO

CONTENIDO
- index.html: estructura y contenido del portfolio.
- styles.css: diseño adaptable a móvil, tablet y ordenador.
- script.js: menú móvil y año automático.

CÓMO VERLO
1. Descomprime el archivo ZIP.
2. Abre la carpeta portfolio_valentin.
3. Haz doble clic en index.html para abrirlo en el navegador.

CÓMO PERSONALIZARLO
- Edita index.html para actualizar textos y añadir proyectos reales.
- Añade imágenes a la carpeta assets y enlázalas desde index.html.
- No se han añadido datos de nacimiento ni domicilio por privacidad.
- El apartado de proyectos queda preparado para incorporar trabajos reales; no se han inventado proyectos.

PUBLICARLO
Puedes subir estos archivos a un repositorio de GitHub y activar GitHub Pages desde la configuración del repositorio.
